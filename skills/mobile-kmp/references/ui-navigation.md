# KMP: UI and navigation

Shared Compose Multiplatform UI, adaptive layouts and resources, and navigation.

| Guide | What it covers |
|---|---|
| [kotlin-ui-compose-multiplatform](ui-navigation/kotlin-ui-compose-multiplatform/GUIDE.md) | Use when designing, implementing, or reviewing shared UI in Compose Multiplatform projects, including state-driven architecture, composable decomposition, layout/modifier discipline, adaptive behavior, and previewable shared UI in common source sets. |
| [kotlin-ui-adaptive-resources](ui-navigation/kotlin-ui-adaptive-resources/GUIDE.md) | Use when designing, implementing, or reviewing adaptive Compose UI for KMP or Android projects — window-size layouts, adaptive navigation, canonical layouts, multi-window support, and resource strategy. |
| [kotlin-navigation-compose-multiplatform](ui-navigation/kotlin-navigation-compose-multiplatform/GUIDE.md) | Use when designing, implementing, or reviewing navigation in Compose Multiplatform projects — route modeling, back stack ownership, argument passing, NavOptions, conditional flows, deep links, and adaptive navigation UI. |

Each guide lives in its own folder. Check the installed Compose Multiplatform and navigation library versions before applying version-specific API advice. Other guides named in the text are listed in the [theme tables of mobile-kmp](../SKILL.md).
