# Android: Build, performance and tooling

AGP 9 upgrades, R8 keep rules, profiling with Android Studio and Perfetto, and the Android CLI.

| Guide | What it covers |
|---|---|
| [agp-9-upgrade](build-and-performance/agp-9-upgrade/GUIDE.md) | Upgrades, or migrates, an Android project to use Android Gradle Plugin (AGP) version 9. |
| [r8-analyzer](build-and-performance/r8-analyzer/GUIDE.md) | Analyzes Android build files and R8 keep rules to identify redundancies, broad package-wide rules, and rules that subsume library consumer keep rules. |
| [android-profiler](build-and-performance/android-profiler/GUIDE.md) | Manages Android performance profiling and debugging. |
| [android-cli](build-and-performance/android-cli/GUIDE.md) | Provides instructions for installing and using the `android` CLI. |

Each guide lives in its own folder with its references and scripts. Relative paths in a guide — and `<repo_root>` where a guide uses it — refer to that guide's folder.
