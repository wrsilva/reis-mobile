# Android: Other form factors

Wear OS, Android TV and display glasses.

| Guide | What it covers |
|---|---|
| [wear-compose-m3](devices/wear-compose-m3/GUIDE.md) | Expert guidance for working with Wear OS Compose Material3. |
| [leanback-to-compose-tv-migration](devices/leanback-to-compose-tv-migration/GUIDE.md) | Provides instructions and architectural patterns for migrating Android TV applications from legacy Leanback UI Toolkit, Android Views, or Support Fragments to Jetpack Compose for TV (androidx.tv). |
| [display-glasses-with-jetpack-compose-glimmer](devices/display-glasses-with-jetpack-compose-glimmer/GUIDE.md) | Provides guidelines for developing projected Android XR apps for display glasses using the Jetpack Compose Glimmer UI toolkit. |

Each guide lives in its own folder with its references and scripts. Relative paths in a guide — and `<repo_root>` where a guide uses it — refer to that guide's folder.
