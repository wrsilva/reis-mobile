# Android: Identity

Credential restore and verified email with Credential Manager.

| Guide | What it covers |
|---|---|
| [restore-credentials](identity/restore-credentials/GUIDE.md) | Provides knowledge and workflows to implement Android's Restore Credentials feature using the androidx.credentials library. |
| [verified-email](identity/verified-email/GUIDE.md) | Provides a complete workflow for implementing verified email retrieval on Android Credential Manager API. |

Each guide lives in its own folder with its references and scripts. Relative paths in a guide — and `<repo_root>` where a guide uses it — refer to that guide's folder.
