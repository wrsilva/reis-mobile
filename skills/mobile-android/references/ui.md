# Android: UI and navigation

Jetpack Compose, adaptive layouts, edge-to-edge, styles, XML-to-Compose migration and Navigation 3.

| Guide | What it covers |
|---|---|
| [adaptive](ui/adaptive/GUIDE.md) | Instructions to make or update an app's UI so that it adapts to different Android devices including phones, tablets, foldables, laptops, desktop, TV, Auto and XR. |
| [edge-to-edge](ui/edge-to-edge/GUIDE.md) | Use this skill to migrate your Jetpack Compose app to add adaptive edge-to-edge support and troubleshoot common issues. |
| [styles](ui/styles/GUIDE.md) | Use this skill to integrate the Jetpack Compose Styles API into an Android project. |
| [migrate-xml-views-to-jetpack-compose](ui/migrate-xml-views-to-jetpack-compose/GUIDE.md) | Provides a structured workflow for migrating an Android XML View to Jetpack Compose. |
| [navigation-3](ui/navigation-3/GUIDE.md) | Learn how to install and migrate to Jetpack Navigation 3, and how to implement features and patterns such as deep links, multiple backstacks, scenes (dialogs, bottom sheets, list-detail, two-pane, supporting pane), conditional navigation (such as logged-in navigation versus anonymous), returning results from flows, integration with Hilt, ViewModel, Kotlin, and view interoperability. |
| [navigation-event](ui/navigation-event/GUIDE.md) | Intercept back gestures and run Predictive Back animations using the NavigationEvent (androidx.navigationevent) library in Compose Android. |

Each guide lives in its own folder with its references and scripts. Relative paths in a guide — and `<repo_root>` where a guide uses it — refer to that guide's folder.
